# Kronos vs AlphaZeroBeta: A Reproducible Comparative Benchmark of Financial AI Models

A controlled, leakage-free comparison of two very different financial machine
learning systems inside **one** evaluation protocol: identical data, identical
investable universe, identical walk-forward folds, identical transaction costs
and identical portfolio constraints.

| | |
|---|---|
| **Market** | S&P 500 (`^GSPC` benchmark) |
| **Sample** | 2013-06-03 .. 2025-01-14 (476 tickers) |
| **Out-of-sample** | 22 non-overlapping 6-month walk-forward folds, Jan 2014 .. Dec 2024 |
| **Investable set** | top 100 names by trailing 60-day dollar volume (identical for all arms) |
| **Costs** | 5 / 15 bps per side, 30 bps/yr borrow; sensitivity at 0x, 1x, 2x |
| **Constraints** | market-neutral arms: `sum w = 0`, `sum|w| <= 1`, `w_i in [-1,1]` |
| **Seeds** | RL arm: 1 seed on all 22 folds, 3 seeds on a fold subset |

---

## Abstract

Financial AI is split between forecasting-first foundation models and
decision-first reinforcement-learning agents. The two are scored with
incompatible metrics, so published results cannot be compared. This repository
puts a financial K-line foundation model (Kronos, zero-shot) and a CNN-GRU
recurrent-PPO market-neutral portfolio agent (AlphaZeroBeta, retrained per
fold) through the same protocol and reports what actually happens, including a
partial reproduction of AlphaZeroBeta's published S&P 500 results with every
deviation documented. The paper, tables and figures are generated from the run
artefacts; no experimental number is hand-typed.

## Models

**Kronos** — decoder-only transformer pre-trained on large collections of K-line
records. A specialised tokenizer quantises OHLCV-style bars into discrete
tokens; the transformer is pre-trained autoregressively over them. Used here
**zero-shot** with the officially released `Kronos-small` checkpoint
(24,741,376 parameters, 512-token context), no fine-tuning.

**AlphaZeroBeta** — CNN-GRU actor-critic trained with recurrent PPO. A
multi-resolution observation (daily/weekly/monthly stacked on the channel axis)
passes through Conv1d(32,8,4) → Conv1d(64,4,2) → Conv1d(64,3,1) → GRU(512) →
shared FC(512) → policy and value heads. The policy emits dollar-neutral
weights directly. Reward balances risk-adjusted excess return against a
benchmark-correlation penalty and a turnover penalty.

**These are not the same kind of object.** Kronos forecasts; AlphaZeroBeta
decides. That asymmetry drives the whole design: see
[`docs/methodology.md`](docs/methodology.md).

## Dataset

Public daily bars, retrieved at run time (not redistributed here).

- **Source:** public market-data endpoint via `yfinance`; index membership from
  the public index constituent lists.
- **Adjustment:** OHLC scaled by `AdjClose/Close`; the factor is same-day, so no
  future corporate action enters a feature.
- **Returns:** adjusted close-to-close simple returns.
- **Investable set:** top 100 by trailing 60-day mean dollar volume, recomputed
  per date, identical across all arms.
- **Known bias:** current index membership (survivorship). Stated, not hidden.

## Experimental protocol

```
walk-forward:  train 756d (3y) -> validate 126d (6m) -> test 126d (6m), step 126d, 22 folds
execution:     weights formed from info <= t-1, earn the return of t
costs:         5 bps/side top liquidity decile, 15 bps/side otherwise, 30 bps/yr borrow
sensitivity:   0x / 1x / 2x
projection:    centre -> project onto L1 ball radius 1 -> clip to [-1, 1]
seeds:         RL arm 1 seed on all folds; 3 seeds on folds {0, 7, 14}
stats:         21-day block bootstrap (5000 resamples), Diebold-Mariano, Newey-West (lag 5)
```

Frozen in [`experiments/configs/base.yaml`](experiments/configs/base.yaml)
before any test-window result was computed.

## Reproduction

```bash
# 1. environment
uv venv .venv && source .venv/bin/activate && uv pip install -r requirements.txt

# 2. everything from cached artefacts
python experiments/run_all.py

# or re-run the GPU arms first (needs the GPU host, see docs/reproduction.md)
python experiments/run_kronos.py
python experiments/run_alphazerobeta.py
python experiments/run_baselines.py
python code/backtest/run_backtest.py
python code/statistics/generate_tables.py
python code/statistics/seed_sensitivity.py
python code/statistics/to_latex.py
python code/statistics/generate_figures.py
make -C paper paper

# 3. tests
python tests/test_core.py
```

`run_all.py` runs data → signals → backtest → tables → figures → paper and
fails loudly if any stage fails.

## Limitations

One market (S&P 500), one decade, daily frequency. Current index membership
(survivorship bias). Price and volume only — no fundamentals, analyst revisions
or sentiment. The RL arm trains under a reduced compute budget relative to the
source study and with one seed on the full fold set. Kronos is evaluated
zero-shot only. No forecasting claim is made about AlphaZeroBeta, which does
not emit forecasts. Details and the full threats-to-validity discussion are in
the paper.
